# CARO LINE AI starter
Kotlin + Jetpack Compose starter: JARVIS-style dashboard, speech input via Android Speech Recognizer, Text-to-Speech, local time/date/flashlight/YouTube/browser commands.

## Build
Push this project to a GitHub repository. The included GitHub Actions workflow generates the Gradle wrapper and builds a debug APK. Download the APK from the successful workflow run's Artifacts section.

## Limits
Speech recognition can require internet depending on Android speech service and installed language packs. This starter does not include online AI, SMS, call answering, WhatsApp automation, or notification reading. Test on a real device.
